How It Works

1

Encrypt in browser

A 256-bit AES key is derived from your password using PBKDF2 (100,000 iterations). Your file and an integrity hash are encrypted locally via the Web Crypto API.

2

Upload encrypted data only

Only the encrypted ciphertext, salt, and IV are transmitted to the server. Neither your plaintext file nor your password ever touches the network unencrypted.

3

Decrypt with password

The recipient enters the password to decrypt the file in their browser. The server automatically removes the encrypted payload immediately after download.
